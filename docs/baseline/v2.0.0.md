# Baseline: BlockSprint v2.0.0

Captured on 2026-11-15 from branch `v2` at `b028c52` (P7.8, the last code change before the tag). Machine: the development laptop (Intel Core i5-6300U, 2 cores, Windows 10 Pro 19045), on mains power, MSVC Release, local loopback. The 1.0 figures are from [v1.0.0.md](v1.0.0.md); the 1.0 engine column from [bench_core.md](bench_core.md) ("before P1.11"). This laptop varies by up to ±12% between identical runs, so every figure is the best of several.

## Engine (`bench_core`, 200,000 operations per workload)

Operations per second, best of 3 runs of `bench_core` (each run itself the best of 3 repeats). "Engine" times the engine call alone; "+orders" includes building the order object.

| Workload | Config | 1.0 engine | 2.0 engine | 2.0 +orders | Speed-up |
| :--- | :--- | ---: | ---: | ---: | ---: |
| passive | sim | 57,773 | **2,526,238** | 2,111,984 | 44× |
| passive | live | 11,536 | **1,072,953** | 989,317 | 93× |
| matching | sim | 39,382 | **2,465,429** | 1,833,122 | 63× |
| matching | live | 12,908 | **981,724** | 871,175 | 76× |
| mirror | sim | 45,690 | **3,091,267** | 2,097,533 | 68× |
| mirror | live | 9,564 | **1,078,837** | 930,185 | 113× |

`sim` is the simulator's configuration (no locking, no callbacks); `live` locks and calls every callback, as the server does. These are 4-14% below the best figures recorded at P1.18 ([bench_core.md](bench_core.md)), within this machine's spread; nothing in the matching path changed since.

## Reproduce

```
cmake --build build --config Release --target bench_core bench_sim bs_sim crypto_matching_engine
build\Release\bench_core.exe
build\Release\bench_sim.exe data/packed/binance_spot_btc_eth_1110/BTCUSDT.bse --repeat 2
build\Release\crypto_matching_engine.exe        # then, in another terminal:
uv run python scripts/perf_test.py
uv run python -m research.live.paper_session replay --session data/paper/2026-11-14_quoter_btc_1 --seeds 1 2 3
uv run python -m research.analytics.parity data/paper/2026-11-14_quoter_btc_1 data/paper/2026-11-14_quoter_btc_2 data/paper/2026-11-14_quoter_btc_3
```
